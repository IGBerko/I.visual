# I.Visual - The Ultimate Client-Side Performance & Visual Tweak Mod

Welcome to **I.Visual**, a highly optimized, modern, and FPS-friendly client-side modification designed to enhance your gameplay experience in Minecraft 1.20.1. This mod is tailored for players who want to clear their screens from annoying vanilla clutter, improve in-game visibility, and maintain tactical awareness without sacrificing computer performance or game aesthetics.

## Key Features

* **Custom Modern GUI Menu:** Say goodbye to boring vanilla buttons. I.Visual features a sleek, dark-themed floating user interface with responsive neon-colored buttons that change states instantly when toggled.
* **Smart Entity ESP:** Features a fully optimized, color-coded 3D box overlay around entities. To prevent visual mess and retain a fair gameplay environment, the ESP respects depth testing, meaning it will automatically hide when entities are behind walls or terrain.
* **Dynamic Color Differentiation:** Quickly identify targets with your peripheral vision. Monsters are highlighted in Red, passive animals in Green, and neutral entities or villagers in Golden Yellow.
* **Minifire Tweak:** Getting set on fire will no longer blind you. The annoying fire overlay is heavily lowered on your screen, freeing up your field of view for intensive combat scenarios.
* **Low Shield Model:** Shields in vanilla Minecraft block almost a third of your right-hand screen. This feature subtly lowers the shield model position, giving you back your crucial right-side awareness.
* **No Pumpkin Blur:** Instantly eliminates the annoying black carved pumpkin silhouette overlay when wearing a pumpkin on your head. Perfect for Enderman farming or tactical PvP.
* **No Powder Snow Freeze Blur:** Removes the annoying frozen vignette frostbite overlay when stuck inside powder snow blocks.
* **No Sky Elements (FPS Boost):** Completely disables heavy vanilla cloud rendering, the sun, and the moon to give a noticeable performance boost for lower-end computer setups.

## Commands & Usage

You can easily interact with the mod or check its status directly from the game chat using the official command:
* `/!ivis -v` - Displays the current version of the mod, running build type, and confirms that the client-side module is active.

## Installation Guide

1. Make sure you have the correct version of **Minecraft Forge for 1.20.1** installed.
2. Download the latest compiled `.jar` file from our official Files tab.
3. Drop the downloaded file directly into your local `.minecraft/mods` directory.
4. Launch the game, bind your custom menu key if necessary, and enjoy a cleaner Minecraft world!
